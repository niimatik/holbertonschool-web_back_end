# Projet Node.js – Exercices pratiques

## 📚 Description

Ce projet contient une série d’exercices pratiques permettant de découvrir et de maîtriser **Node.js**, **Express.js**, ainsi que les outils modernes utilisés dans le développement backend JavaScript.

L’objectif est de comprendre le fonctionnement de Node.js, la création de serveurs HTTP, la gestion des fichiers, l’utilisation des modules, et la mise en place d’un environnement de développement professionnel avec tests et linting.

---

## 🎯 Objectifs pédagogiques

À la fin de ce projet, vous serez capable d’expliquer, sans l’aide de Google :

- Comment exécuter du JavaScript avec **Node.js**
- Comment utiliser les **modules Node.js**
- Comment lire des fichiers avec des modules Node.js spécifiques
- Comment utiliser `process` pour accéder :
  - aux arguments de la ligne de commande
  - aux variables d’environnement
- Comment créer un petit serveur HTTP avec **Node.js**
- Comment créer un serveur HTTP avec **Express.js**
- Comment créer des routes avancées avec **Express.js**
- Comment utiliser **ES6** avec Node.js grâce à **Babel**
- Comment utiliser **Nodemon** pour accélérer le développement

---

## 🛠️ Prérequis techniques

- **Node.js** version **20.x.x**
- **npm**
- Système d’exploitation : **Ubuntu 20.04 LTS**

---
